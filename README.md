## :information_source: About

🏆 A gamified platform for young people aged 16 to 20, made by team #113 at the CCR hackathon. Young people answer knowledge tests in several areas and earn awards (money or other prizes) according to their score and participation. Partner companies, with their own profile on the platform, see the results and can filter candidates in a complete database.

This repository has the young person's area: dashboard, scores, ranking and awards, with a sidebar and a notifications bar.

Built in 2021.

## :arrow_forward: Run

You need [Node.js](https://nodejs.org/) and [Yarn](https://yarnpkg.com/). In the project folder:

```bash
# Install dependencies
yarn

# Start the development server
yarn start
```

> The app opens at <http://localhost:3000>.
